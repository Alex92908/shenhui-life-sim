# 深惠人生模拟 · 电脑高配版

深圳 / 惠州双城生活模拟游戏：30 天一个人生周期，在深圳或惠州开始过日子——上班赚钱、吃饭睡觉、坐地铁、骑行、租房、装修、认识街坊，赶上 2026 年 11 月深圳 APEC 领导人周，还能当志愿者、记者、接驳司机去会场打卡。

## 玩法设计：大地图只做路线，弹出经历全是真实的

- **大地图 = 路线层**：低多边形 3D 双城地图，按真实地理方位排布，只负责导航、选地点、看位置关系、选出行方式。84 个地点（深圳 52、惠州 32），深圳全地铁网 + 惠州城际/高铁，步行 / 骑行 / 电动车 / 公交 / 打车 / 地铁 / 高铁九档速度各不相同。
- **弹出经历 = 真实层**：住宿、搭乘、吃饭、工作、逛街等一切弹出经历都用真实照片做底（真实地点的实拍），配真实信息（地址、价格、营业时间、小贴士）和互动选择，目标是玩着就认识这座城市。
- **认识深圳图鉴**：每到一个真实地点，解锁它的实拍和城市知识；按真实地铁线做一日游路线任务；拍照认地方小游戏；NPC 带路讲真实故事。中英双语。
- **真实天气**：天色天气跟深圳 / 惠州实时天气走，下雨天游戏里真的下雨。
- **APEC 领导人周活动**：11 月 14–19 日每天一个任务，按真实日程去香蜜湖、前海、太子湾三个会场打卡上岗，玩家只能当志愿者、记者、司机。
- **NPC 模拟**：11 位 NPC 有性格、心情、作息和记忆，会记住你的帮助、礼物和得罪，在街坊墙上发动态、评论。
- **多人联机**：玩家共享一个世界，头像每 6 秒同步，深惠聊天频道、动态墙、排行榜。
- **LOL 式小地图**：角落小地图实时显示玩家位置、NPC 和目的地，点小地图快速定位。

## 地铁线网数据

深圳全线网（1–16、20 号线，2/8 号线贯通，6 号线支线，13 号线，坪山云巴，龙华有轨电车，穗深城际深圳段，共 381 站）由 `tools/metro/gen_sz_metro.py` 从 OpenStreetMap 生成到 `client/src/metro-sz.ts`，不要手改生成文件。

- 站序来自 OSM 线路关系，站点坐标由真实经纬度拟合到游戏微缩地图（约 1 公里/格）；有游戏地点的车站（罗湖口岸、深圳北站、福田口岸等）钉在地点建筑上，其余站点平滑过渡，东部远端向内收拢以留在陆地上。
- 票价按深圳地铁里程计价（起步 4 公里 2 元，4–12 公里每 4 公里 +1 元，12–24 公里每 6 公里 +1 元，24 公里以上每 8 公里 +1 元），里程用真实站点距离。
- 更新：`python3 tools/metro/gen_sz_metro.py --fetch`（重新下载 OSM 快照）或直接 `python3 tools/metro/gen_sz_metro.py`（用仓库里的快照 `tools/metro/sz-osm-routes.json`）。
- 线路数据 © OpenStreetMap contributors，按 [ODbL](https://www.openstreetmap.org/copyright) 授权。惠州的城际 / 高铁线仍是手工数据（在 `client/src/data.ts`）。
- 每个地铁站都是可以站的地方（`st:<站名>`）：坐到哪站就在哪站下车，途中任意一站也能提前下车，按实际里程扣费。

## 地标缩影

大地图上每个地点都是真实建筑 / 场所的低多边形缩影（`client/src/landmarks.ts`），不再是统一的方块楼：平安金融中心、腾讯滨海大厦、春茧、大运中心、市民中心、深圳北站、宝安机场 T3、各口岸联检楼、城中村握手楼、东门老街、世界之窗、大鹏所城、弘法寺、盐田港吊机等；另有不对应地点的天际线地标（春笋、京基100、地王大厦、湾区之光摩天轮）。山区地点是带登山道和山顶亭子的山，公园、海滩各有自己的模型。

- 所有静态模型启动时按材质合并成整城几十个网格，绘制调用比原来的方块楼还少；摩天轮单独保留以便转动，点选用不可见的包围盒。
- 新增地点：在 `SPECIFIC` 里按 `城市:地点id` 加一个函数；没有专门模型的地点按类型（口岸、山、海滩、公园）自动套用，再没有就保留原来的方块楼。

## 大厂跳槽

深圳地图上有 10 个大厂总部（腾讯滨海大厦、腾讯企鹅岛、抖音集团后海中心、百度、大疆天空之城、华为坂田、中兴、招商银行、万科中心、比亚迪），平安银行大厦也算平安的公司。开局在「科技园公司」（小创业公司）上班。

- 在总部点「投简历 · 面试」：技能 / 经验 / 职级够了就拿 offer，再点「接受 offer」跳槽；每家每天面一次，没过也加 1 点经验。招行、平安面试要穿正装。
- 每家日薪倍率、上班耗能、心情、加班费不同（数据在 `client/src/data.ts` 的 `COMPANIES`），有食堂的公司员工能 ¥12 吃饭。
- 手机「职业中心」里能看各家门槛和自己差多少，一键过去面试。惠州仍只有仲恺公司。

## 长线玩法（跨局保留）与联机社交

一局 30 天过完不再是终点。以下进度存在浏览器里（`client/src/meta.ts`，localStorage 键 `shhr-meta-v1`），每一局都接着累计，右侧竖条「🎫 集章」页能看全部进度：

- **地铁集章**：上车、下车、换乘的站和走到的站自动盖章，集齐一整条线奖励 ¥(100 + 10×站数)。
- **城市图鉴**：到过的游戏地点和 OSM 真实地点按类记下。
- **连续上线**：按真实日历，每天第一次进游戏在每日任务弹窗里领奖，7 天封顶。
- **本周目标**：每周 6 个目标（盖章、新地点、上班、坐地铁、面试、送礼），完成领钱。
- **成就 / 称号**：15 个成就，解锁后可佩戴称号，显示在状态卡、聊天在线列表和集章排行里。
- **每日城市事件**：按真实日期 + 城市 + 游戏日生成，同一天的玩家看到的一样（台风、绿色出行日、商场大促、美食节、发奖金、音乐会、大厂开放日、地铁站快闪），效果真实作用在票价、餐饮、购物、工资、面试门槛、打车和海边景点上。

联机（需要 `drizzle/0004_social_collections.sql` 迁移，独立服务器启动时自动执行）：

- **送礼**：聊天页给在线玩家送奶茶 / 早餐 / 红包 / 内推，对方下次心跳时领取；内推让对方面试你公司门槛降低。每人每 24 小时最多送 10 份。
- **同事**：和在线的同公司玩家一起上班心情 +3，在线列表标出「同事」。
- **排行**：排行页新增公司排行（最近 7 天在深圳上班的玩家按公司汇总存款）和跨局集章排行。

## 分享、邀请、云存档、手机版、防作弊

- **📤 分享**（顶栏）：生成 1080×1350 战绩卡（存款、公司、站章、图鉴、成就、今日事件、邀请链接），手机上走系统分享面板，电脑上保存图片或复制邀请链接。
- **邀请链接** `?invite=<玩家>&from=<昵称>&co=<公司>`：朋友进来开局多 ¥100，还带邀请人公司的内推；朋友报到后邀请人收到 ¥200（每个新玩家只算一次）。
- **云存档码**（「🎫 集章」页顶部，10 位）：存档和跨局进度安静 12 秒后、或切到后台时自动上传；换设备在开始页输入存档码即可接着玩。
- **省电画质**：手机 / 小屏 / 低内存设备默认开启（1x 像素、无阴影、无后期、树更少），「🎫 集章」页可切换；顶栏在窄屏上是一行可横向滑动。
- **防作弊**：服务器比对每次心跳，存款超出一天可能挣到的上限、一次跳两级职级、几秒内多出几十个站章，就把玩家标记为可疑并移出所有排行榜（不删数据，新开一局清除标记）。
- 部署见 [DEPLOY.md](DEPLOY.md)（Muse / Docker / Node 三种方式）。

## 公共服务（真实）

- 医院（含 24 小时急诊标记）、药店、派出所 / 警务室、游客 / 志愿服务中心都来自 OpenStreetMap，带中英文名，OSM 上有的电话、地址、营业时间一并显示（电话可直接点拨）。原来路边随机摆的装饰性 🏥🚓⛽ 小楼已移除。
- 每个地点面板有「🆘 附近服务 · Emergency & Services」：120 / 110 / 119 / 12345 一键拨号，加上最近的急诊医院、药店、派出所、游客中心，APEC 会场默认展开。
- 「附近」按**真实距离**算：真实地点用自己的经纬度，游戏地点用它所在的地铁站（手工摆放的建筑不是等比例的，用地图距离会指错街区）。
- 数据可能过时，界面上注明以实际为准、紧急情况直接拨打 120 / 110。

## 城市地点数据

深圳约 320 个真实地点（公园、湿地、海滩、山峰、商场、医院、大学、图书馆、博物馆 / 美术馆、剧院、体育场馆、主题乐园、景点、古迹）由同一个生成器从 OpenStreetMap 生成到 `client/src/places-sz.ts`，用和地铁站相同的坐标拟合，所以和车站的相对位置一致。

- 筛选规则在 `tools/metro/places.py`：有 Wikidata 条目的优先，公园 / 商场 / 医院按面积筛掉小的，每类有上限；和游戏里手工做的地点重名的不重复显示。
- 游戏里地点 id 为 `pl:<OSM id>`，按类型套用现有玩法（公园 / 海滩 / 古迹可打卡、商场可购物、医院可看病、大学 / 图书馆可学习、剧院可看演出）。
- 地图拉近后显示地点名，点名字就去；地点面板有「🧭 附近可去」；顶部搜索框能搜到这些地点。
- 更新：`python3 tools/metro/gen_sz_metro.py --fetch-places`（重新下载快照 `tools/metro/sz-osm-places.json`）。

## 运行

这是一个 Muse 空间（TypeScript + React 19 + Three.js + Drizzle + SQLite）项目，运行在 Muse 的托管运行时里。

```bash
bun install
bun run typecheck   # 前后端类型检查
bun run build       # 构建服务端与客户端
```

`package.json` 依赖了 `@hatch/space-sdk`（`file:/opt/hatch/skills/spaces/ts-runtime/dist/space-sdk.tgz`），本地构建需要 Muse 运行时环境。

### 脱离 Muse 独立运行（`standalone/`）

只需要 Node.js 20+，不需要 Muse、不需要 bun，游戏源码（`client/`、`server/`）一行不改：

```bash
cd standalone
npm install          # 装依赖，并把仓库根目录的 node_modules 链到 standalone/node_modules
npm run build        # 用 Vite 构建客户端到 standalone/dist
npm start            # 启动服务端 → http://127.0.0.1:8787
```

开发模式（改代码热更新）：`npm run dev`，打开 http://localhost:5173 。

它怎么替代 Muse：

- `standalone/sdk/` 是一个本地版 `@hatch/space-sdk`，只实现游戏用到的部分：服务端的 `defineAction` / `z` / `ctx.db()`，客户端的 `createActionClient` / `spaceQueryClient` / `SafeAreaTopScrim`。
- `standalone/server.ts` 用 Node + SQLite（better-sqlite3）直接跑 `server/src/actions.ts`，启动时自动执行 `drizzle/*.sql` 迁移，数据存在 `standalone/data/app.db`（可用 `DB_PATH` 改位置）。
- 真实天气改用 [Open-Meteo](https://open-meteo.com/)（免费、无需 key），`WEATHER=off` 可关闭。
- 缺失的实拍照片会自动当作空图处理；把原图放回 `client/src/assets/` 就会显示。
- 联机：`HOST=0.0.0.0 npm start` 后，同一局域网的朋友用你电脑的 IP:8787 打开就能在同一个世界里。
