# 运营手册：上线前、峰会周、每天

后台在 `https://你的域名/#admin`（需要 `ADMIN_TOKEN`）。这几页每天都要看：

| 后台标签页 | 用途 |
|---|---|
| 📣 公告 / 📢 广告牌 | 发更新公告（玩家「🆕 更新」立刻亮红点），替本地商家挂地图广告牌 |
| 意见箱 | 玩家在游戏里提的想法和 Bug |
| 举报 | 私聊骚扰、诈骗、未成年人安全，带聊天上下文，可封号 |
| 风险 / 薅羊毛 | 同设备多号、同网络批量注册、邀请奖励异常 |
| 经济 / 订单 | 被拦下的异常进账、✨ 订单和退款 |
| 数据 | 日活、次日留存、7 日留存、热门事件 |
| 报错 | 玩家端崩溃和报错 |

## 一、上线前（T-5 到 T-1）

- [ ] 合并最新 PR，服务器上 `npm run build`，重启 `npm start`
- [ ] `standalone/.env`：`ADMIN_TOKEN`、登录验证码（Resend / 短信）、Stripe，**关掉** `DEV_LOGIN_CODES`、`DEV_PAYMENTS`，`SOCIAL_REQUIRES_ACCOUNT=1`（详见 [LAUNCH-SETUP.md](LAUNCH-SETUP.md)）
- [ ] 构建时设置 `VITE_OPERATOR_NAME`、`VITE_OPERATOR_CONTACT`（协议里的运营方）
- [ ] 域名 + HTTPS，nginx 反代时 `TRUST_PROXY=1`
- [ ] 每天备份 `standalone/data/app.db`（cron：`cp app.db backup/app-$(date +%F).db`）
- [ ] 真机测试：iPhone Safari、安卓 Chrome、**微信内置浏览器**（把链接发给自己再点开）：抽签开局 → 走一趟地铁 → 打一次卡 → 分享卡
- [ ] 两个真人账号互测：组局 → 合租邀请 → 发一个零工、接活、交付、确认 → 业委会参选、投票
- [ ] 后台发第一条公告，确认玩家端「🆕 更新」亮红点
- [ ] 找 3–5 家本地小店，免费挂第一周广告牌（后台「📢 广告牌」），换他们在店里贴二维码

## 三、每天的运营节奏

**早上（15 分钟）**
1. 后台「数据」：昨天日活、次日留存。留存掉了就去「报错」看有没有崩溃。
2. 「举报」：先处理「未成年人安全」「诈骗」，再处理骚扰。证据确凿直接封号。
3. 「意见箱」：挑 1–3 条今天能改的，记下来。

**下午**：改那 1–3 条，发版。

**晚上 8 点前**：在后台发一条公告，写今天改了什么、明天有什么。写法：
> 🆕 今天：xxx（谢谢 @玩家昵称 的建议）。明天：xxx。

**规则**：每条被采纳的意见，在公告里点名感谢提意见的玩家。这是 Lagos Life 涨人最快的做法：玩家看到自己的意见上线，会拉朋友来。

## 四、广告牌招商（变现第一步）

- 每城 3 块：商场、车站、市场附近。玩家用 300 ✨ 租一周（表白、找室友、给自己的摊位打广告）。
- 本地商家：先送一周，有效果再按周收费，线下收款后在后台挂上。建议起步价：深圳 / 香港 ¥199 一周，惠州 ¥99 一周。
- 广告语要过审：后台挂之前自己读一遍，禁止医疗、贷款、博彩。

## 五、出事了怎么办

| 情况 | 做法 |
|---|---|
| 服务器宕机 | 先恢复，再发公告道歉；补偿可以用「签到奖励」那一套逻辑加一次性发放（需要开发） |
| 有人刷钱 | 「经济 / 订单」里看被拦下的记录；服务器记账会拦住超额进账，排行榜只看服务器余额 |
| 诈骗 / 骚扰 | 封号；在公告里提醒「不要在私聊里给任何人转账、验证码」 |
| 零工纠纷有人恶意刷票 | 陪审要绑定账号；必要时在后台封掉刷票小号 |
| 退款 | Stripe 后台退款，✨ 会自动扣回；退款 ≥2 次的账号会被锁住购买 |
