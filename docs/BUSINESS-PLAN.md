# 湾区人生：账号、付费、运营、防薅羊毛与营收方案

> 方案稿（2026-11-08）。基于现在代码的真实情况写；需要外部账号/资质的部分已标明，不是代码能直接解决的。配套：[GLOBAL-ARCHITECTURE.md](GLOBAL-ARCHITECTURE.md)（技术架构与上架平台）。

## 0. 先说现状里的风险（上付费前必须解决）

| 现状 | 风险 |
|---|---|
| 存档在浏览器 localStorage，**钱、职级、家具都由客户端算** | 改存档就能有无限钱；排行榜靠「心跳跳变」检测（单日 > ¥25,000 才判可疑），挡不住慢慢改 |
| 签到、连续上线、红包、邀请奖励 ¥200 都在**客户端**加钱 | 一旦这些奖励能换任何有价值的东西，就会被刷 |
| 没有账号：清缓存 = 新玩家 | 一个人可以无限开新号刷「邀请奖励」；封号也封不住人 |
| 送礼每天 10 份、私信限频、新号私聊限制、管理后台封号 | 这些已经有，方向对 |

**结论：在「服务器说了算」之前，游戏里任何东西都不能和真钱挂钩**——不卖游戏币、不卖能影响排行的道具、邀请不送真实奖励。

## 1. 账号管理

**阶段 1（上线即做）：游客 + 绑定**
- 继续允许游客秒开玩（门槛低是网页/小游戏的命）；第 2 天起、或首次私聊/组局/付费前，引导绑定账号。
- 绑定方式：国内 — 手机号验证码、微信登录；海外 — Apple / Google / 邮箱验证码。
- 绑定时把现在的匿名 `playerId`、云存档、跨局档案迁移进账号，一个都不丢。
- 账号页：改昵称（每 30 天一次）、绑定/解绑、导出数据、**注销账号**（法律要求，GDPR/PIPL 都要），拉黑名单、举报记录。

**阶段 2（付费前必须做）：服务器权威**
- 存档搬到服务器；客户端只发「我要做什么」，服务器校验（时间、冷却、位置、余额）再改数据。
- 钱只记**流水账**（每一笔收入/支出一条记录），余额是算出来的——可审计、可回滚。
- 风控字段：设备指纹、注册 IP、首次支付账户、实名状态（国内）、风险分。

**国内专属：** 实名认证 + 未成年人防沉迷（时段、时长、单笔和月度充值上限）是网络游戏上线的硬性要求。

## 2. 货币设计：三种钱，分开管

| 货币 | 怎么来 | 怎么花 | 能买吗 |
|---|---|---|---|
| **游戏币 ¥/HK$**（现在的「存款」） | 上班、接活、玩法、剧情 | 房租、吃饭、出行、家具、衣服、玩法门票、罚款 | **不卖**。每个赛季（自然月）清零，排行榜才公平 |
| **档案点**（现在已有） | 每局结算、街坊故事、组局 | 永久传承 | **不卖**——这是长期成长的骄傲感，卖了就不值钱 |
| **星光 ✨（新，付费货币）** | 充值；少量活动/成就也能赚到 | 只买**外观和便利**：服装、发型、家装主题、车皮肤、宠物、明信片相框、改名卡、额外存档位、私人组局房 | 能买，**不卖属性、不卖钱、不卖排名** |

原则：
- **不做抽卡/开箱**：国内要求公示概率且受严格监管，比利时、荷兰等地直接禁止；用「直接购买 + 赛季通行证」代替。
- **不能玩家之间转账/交易**：送礼只送固定的小礼物（已有），杜绝工作室和洗钱。
- **星光不可提现、不可转让**，退款就扣回。

## 3. 怎么花钱（玩家视角）和怎么拿钱

**游戏里（游戏币）——已经有的循环：**
- 收入：上班（大厂工资更高）、加班、接活、搞钱类玩法（摆摊、倒卖、直播、代驾）、剧情和成就奖励、组局加成。
- 支出：房租（每周六）、吃饭、出行（地铁、打车、自驾油费和停车）、玩法门票、家具装修、衣服、罚款（案底）、医药费、宿醉。
- 现在的紧张感来自「房租 + 30 天目标 + 真实冷却」，方向正确；后续每加一个收入点，要配一个支出点（**通胀管控**：每赛季看「人均存款中位数」，偏高就加房租或物价事件）。

**付费点（星光 / 现金）：**
1. **赛季通行证**（每个自然月一期，¥28 / HK$32 / US$3.99）：免费线 + 付费线，任务就是游戏里本来就要做的事（钓到 5 种鱼、和真人组局 3 次、走完一条街坊剧情）。奖励是外观、明信片、星光返还。**这是最适合本作的主力付费**：和每月赛季、真实日历天然对齐。
2. **会员月卡「深漂会员」**（¥18 / US$2.99 每月）：每日少量星光、额外云存档位、私人组局房（可设密码约朋友）、照片无水印导出、名字颜色。不给属性。
3. **外观直售**：衣服、家装主题包（「香港唐楼复古」「深圳湾海景」）、车皮肤、宠物、头像框。
4. **城市扩展**：新城市（广州、澳门……）基础内容免费，付费的是该城市的外观包和剧情 DLC。

## 4. 充值与支付（需要外部资质）

| 平台 | 支付方式 | 门槛 | 分成 |
|---|---|---|---|
| 国内网页 | 微信支付、支付宝 | **企业主体 + 版号**（游戏内付费） | 渠道费约 0.6% |
| 微信小游戏 | 微信虚拟支付 | 版号；iOS 上虚拟支付受苹果规则限制 | 平台分成 |
| iOS / Android App | Apple IAP、Google Play Billing | 开发者账号；国内安卓商店要版号 | 15–30% |
| Steam | Steam 钱包 / 微交易 | Steamworks 账号 | 30% |
| 海外网页 | Stripe 或 Paddle（Paddle 代收税，个人/小团队省事） | 公司或个人商户 | 约 3–5% |

技术要点（我可以写的部分）：
- 服务端下单 → 支付回调**服务端验签** → 幂等发货（同一订单号只发一次）→ 写流水。客户端永远不直接加星光。
- 退款回调：扣回星光，扣不够就锁付费功能。
- 每日对账：支付平台账单 vs 我们的流水。
- **先用 Stripe 测试模式做完整链路**，不碰真钱；国内上线前接微信/支付宝。

**建议顺序：** 国内在拿到版号前**完全免费、不开付费**（只积累用户）；**先在海外（网页 Stripe/Paddle + Steam）开付费**，这条路不需要版号。

## 5. 防薅羊毛

**现在就该改的（不管付不付费）：**
1. **邀请奖励改成延迟发放**：被邀请人必须「绑定账号 + 连续 3 天活跃 + 完成 1 次真人组局」才算有效邀请；每个邀请人每周有上限（例如 10 人）；同设备/同 IP 段的新号不计。
2. **签到、连续上线、红包等奖励改由服务器发**：服务器按服务器时间判断今天领没领。
3. **奖励只发「不能变现的东西」**：游戏币（赛季清零）、档案点、外观碎片——不发星光大额、不发现金券。
4. **新号冷却**：注册 24 小时内不能私聊陌生人（已做）、不能参与排行榜奖励、不能领邀请奖励。

**付费后加的：**
5. **首充 / 新人礼包**：按「支付账户 + 实名」去重，而不是按游戏账号。
6. **兑换码**：一码一用、绑定活动和有效期、每个账号限领、生成和核销都记日志。
7. **异常检测**（在现有后台上加）：同设备多账号、批量注册时间聚集、收入曲线异常、只领奖不玩的「领完就走」账号 → 进人工审核队列或自动冻结奖励。
8. **排行榜奖励只给外观/称号**，不给星光或现金，羊毛党就没有动力。
9. **退款滥用**：同一账号多次退款 → 禁止再次购买。

## 6. 运营

**内容日历（跟真实日历走，这是本作独有的优势）：**
| 月份 | 赛季主题 |
|---|---|
| 11 月 | 湾区国际峰会周（已做） |
| 12 月 | 年末加班季、圣诞维港灯饰、跨年 |
| 1–2 月 | 春运抢票、回乡还是留深过年、深港过年习俗 |
| 4 月 | 清明、春游、梧桐山杜鹃 |
| 6 月 | 荔枝季、端午龙舟、毕业季找工作 |
| 7–9 月 | 台风季（真实天气联动）、暑假实习生 |
| 10 月 | 国庆黄金周、大鹏音乐节 |

**每周节奏：** 周一新的城市事件，周五晚「全城组局夜」（同时段上线的人多，组局更容易成），周日赛季排行榜快照。

**社区：** 玩家群（微信群/Discord）、「街拍大赛」（游戏内摄影作品投稿、点赞，第一名做成游戏里的明信片）、玩家投票下一个城市。

**看的指标（后台已有一部分）：** 次日/7 日/30 日留存、日活、组局率（有真人一起玩的人留存会高很多）、付费率、ARPPU、每用户平均收入、通行证完成率、举报率。

## 7. 推广与营收

**目标用户：** 深漂、港漂、湾区上班族（「这就是我的生活」）；想来深圳/香港工作或旅游的人（「先在游戏里过一遍」）；海外华人和对中国城市好奇的外国玩家（中英双语、真实地点）。

**推广渠道：**
- 小红书 / 抖音 / B 站：「在游戏里过一天深漂/港漂」短视频；真实地点打卡对比（游戏截图 vs 实拍）；搞笑结局截图（「被房东请出门」「加班战神」）。分享卡和邀请链接已经有。
- 城市话题借势：真实天气（台风天）、真实活动日（峰会周、马拉松）、真实新闻（新地铁线开通 → 游戏里同步开通）。
- 海外：Steam 新品节、Reddit r/China r/HongKong、YouTube「city life sim」。

**营收来源（按建议优先级）：**
1. **赛季通行证 + 会员 + 外观**（C 端，主力）。
2. **城市与商家合作（B 端，本作独有）**：
   - 文旅局 / 景区：游戏里的真实景点卡片、一日游路线、打卡活动，可以做官方合作（也顺带解决照片授权问题）。
   - 商家：餐厅、商场在游戏里有真实位置——「推荐商家」位（必须标明「推广」）。
   - 招聘：真实企业赞助游戏里的「大厂」剧情或职业线（雇主品牌）。
3. **景点门票分销**：景点卡片上放真实购票链接，拿分销佣金（携程/Klook 等联盟计划）。
4. **激励视频广告**（主要在微信小游戏）：只做「看广告换体力/冷却加速」这种玩家自愿的，**不做强制广告**。

**粗算模型（全是假设，用来定目标）：**
- 日活 1 万 × 付费率 3% × 每月人均付费 ¥30 ≈ **每月 ¥9,000**（C 端）。
- 留存好的话付费率可到 5%，人均 ¥40 → 约 ¥20,000/月。
- B 端合作单个城市/景区一次性或年度合作，通常比早期 C 端收入高，**早期更值得跑 B 端**。
- 成本大头：服务器（日活 1 万级别每月几百到一两千元）、内容制作、审核人力、各平台分成。

## 9. 实施状态（2026-11-08）

| 步骤 | 状态 | 说明 |
|---|---|---|
| 1. 防薅羊毛 | ✅ 已做 | 设备号 + IP 哈希；邀请延迟发放（3 天活跃 + 真人组局，同设备/同网络不算，每周 10 份）；签到/连登/见面礼由服务器发；后台「风险」页 |
| 2. 账号 | ✅ 已做 | 邮箱/手机验证码登录、游客进度并入账号、换设备载入、退出/全设备退出、导出数据、注销；私聊/组局/邀请奖励需要账号 |
| 3. 服务器记账 | ✅ 已做 | 服务器自己记余额：花钱照收，进账受「进账额度」限制（随真实时间回满），超出的被拦下并写进账本、客户端被校正；单次跳涨超过整个额度直接不入账并标记可疑；排行榜只看服务器余额；后台「经济 / 订单」页 |
| 4. 星光商店 | ✅ 已做（测试模式） | ✨ 属于账号、只在服务器、流水不可重复入账；充值包、赛季通行证（每天签到升一级，免费线 + 付费线）、深漂会员（每天 10✨ + 金色昵称）、外观（昵称颜色、称号）；Stripe Checkout + 验签 webhook + 幂等发货 + 退款扣回；退款 ≥2 次锁购买 |
| 5. 你要办的 | ⏳ | 见下 |

**上线前要配置的环境变量（standalone/server.ts）：**

| 变量 | 作用 |
|---|---|
| `RESEND_API_KEY` + `LOGIN_FROM` | 邮箱验证码（Resend） |
| `LOGIN_CODE_WEBHOOK`（+ `LOGIN_CODE_WEBHOOK_SECRET`） | 短信或其他服务商：服务器 POST `{provider, to, code}` |
| `STRIPE_SECRET_KEY`、`STRIPE_WEBHOOK_SECRET`（可选 `STRIPE_CURRENCY`，默认 usd） | 付款；在 Stripe 后台把 webhook 指到 `https://你的域名/stripe/webhook`，事件选 `checkout.session.completed`、`checkout.session.async_payment_succeeded`、`charge.refunded` |
| `ADMIN_TOKEN` | 后台 `#admin` |
| `TRUST_PROXY=1` | 部署在反向代理后面时取真实 IP |
| `VITE_OPERATOR_NAME` / `VITE_OPERATOR_CONTACT`（构建时） | 用户协议和隐私政策里的运营方 |

**只能本地用、上线必须关掉：** `DEV_LOGIN_CODES=1`（验证码显示在页面上）、`DEV_PAYMENTS=1`（模拟付款）。

**还要你来办：** Stripe 账号（先用测试密钥跑通）、邮件/短信服务商、公司主体与 ICP 备案、国内付费需要版号；国内上线还要实名认证和未成年人防沉迷（时长、时段、充值限额），这需要接实名服务商，代码可以后接。

**真实企业名称：** 地图上的公司已改回真实名称（腾讯、华为、百度……），协议里写明「只标示真实位置、玩法和剧情是虚构的、无合作或授权、商标归权利人」。正式商业化前建议请律师看一遍，尤其是涉及加班、裁员等负面剧情的公司。
